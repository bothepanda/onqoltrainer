# Оценка попыток по выгрузке (порядок на каждую пятницу)

Автоматическая оценка на сервере выключена (`STUDY_GRADING` не задан). Оценки делаются после занятия в сессии Claude Code по выгрузке и загружаются в базу. Так они бесплатны в рамках подписки, а проверки кодом (цитата, подсказка, повтор) применяются всё равно.

## Что делаете вы (5 минут)
1. После занятия откройте `/study/admin`, введите ADMIN_TOKEN, нажмите **«Скачать JSON»**. Файл сохранится в «Загрузки» как `onqol-study-ГГГГ-ММ-ДД.json`.
2. Откройте Claude Code в папке `~/onqol-trainer` и напишите: **«оцени выгрузку ~/Downloads/onqol-study-ГГГГ-ММ-ДД.json»**.
3. Когда Claude сообщит, что файл готов (`gradings-import-ГГГГ-ММ-ДД.json`), в `/study/admin` найдите блок **«Загрузить оценки из файла»** и выберите этот файл.
4. Нажмите **«Сравнить»** в блоке «Сравнение первого прохождения и повтора». Тестовые ID (T…) по умолчанию не показываются.

## Что делает Claude (для нового чата)
1. `node scripts/prepare-grading.mjs <выгрузка.json>` печатает рубрику и транскрипты неоценённых завершённых попыток (`--all` для всех, `--attempt <id>` для одной).
2. Оценивает каждую попытку строго по правилам `RULES` в `api/_lib/grader.js`: только реплики резидента, 2 / 1 / 0 (в повторе только 0 и 2), цитата обязательна и дословна, подсказки учитываются по меткам, пункт 11 строго. Записывает `мои-оценки.json` в формате из шапки `scripts/preview-gradings.mjs`.
3. `node scripts/preview-gradings.mjs <выгрузка.json> мои-оценки.json --out gradings-import-ГГГГ-ММ-ДД.json --grader "claude-code-session (<модель>)"` применяет проверки кодом, печатает итоги и что было изменено, собирает файл для загрузки.
4. Показывает пользователю итоги по каждому резиденту и замечания проверок.

## Ограничения, о которых стоит помнить
- Оценивает языковая модель, а не человек. Для публикации возьмите 5 случайных попыток и проверьте вручную (блок «Оценка» у попытки в `/study/admin`: ваши баллы заменяют оценку модели в сравнении).
- В записи каждой оценки сохраняется, кто оценивал (`claude-code-session …`) и версия правил (`grade-1.2-external`). Не меняйте правила оценщика посреди исследования без записи.
- Транскрипты нельзя отправлять в другие сервисы (в согласии указан только Anthropic).
- Разбор, который резидент видит сразу после кейса, при выключенной автооценке свободный: он строится по транскрипту и меткам подсказок, а не по оценке. Если он окажется завышенным, его можно отключить.
